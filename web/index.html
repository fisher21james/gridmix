Grid Mix Display

See what's powering your grid right now, on a 4.3" ESP32-S3 desk display. Install the firmware straight from this page, no software needed.

How it works

  1. Plug the JC4827W543 into your computer with a USB-C data cable (some cables only charge).
  2. Click Install Grid Mix and pick the board from the list. It usually shows as USB JTAG/serial debug unit.
  3. Wait about a minute while it installs. Don't unplug it.
  4. When asked, enter your Wi-Fi name and password. The display connects and remembers it.
  5. Finish setup from your phone at gridmix.local (region, data source, your tariff).

If it doesn't show up

  • Try another USB-C cable or port.
  • Hold the BOOT button on the board while plugging it in, then click Install again.
  • Close anything else using the board, like the Arduino IDE serial monitor.
  • Running Install again later updates to the newest version and keeps your settings.
Grid data: Open Electricity (Australia), U.S. EIA Hourly Electric Grid Monitor (US), Electricity Maps (worldwide). Firmware is open source.
